# Changelog

All notable changes to TableKit are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Project skeleton: Gradle build against IntelliJ Platform 2024.2 (build 242), Kotlin 2.2.21.
- File type registration for `.parquet`, `.parq`, `.pq`, `.xlsx`, `.xlsm`, `.avro`, `.orc`.
- Custom `FileEditor` that replaces the default editor for binary tabular formats and adds a
  secondary tab for `.csv`, `.tsv`, `.jsonl`.
- Plugin and file type icons.
